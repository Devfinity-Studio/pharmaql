# PharmaQL

The Modern Medicine Portal empowering medical representatives and distributors with real-time insights, effortless ordering and intelligent inventory tracking.

## Features
- **Dashboard:** Detailed insights with products, invoices, and sales metrics.
- **Reporting:** Export party-wise and product-wise data into CSV, PDF, or Excel formats.
- **Access Control:** Role-based access for Medical Representatives (MR) and Administrators.
- **Modern UI:** Built using Next.js 15, TailwindCSS, and shadcn/ui.
- **Secure Authentication:** Powered by better-auth.
